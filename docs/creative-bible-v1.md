# Purpose

This document defines the creative direction for the entire project.

It has higher priority than implementation decisions.

Every design, editorial and development decision must follow the principles defined here.

Whenever implementation conflicts with this document, the Creative Bible takes precedence.

---

# Project Vision

This is not a tourism website.

This is not an event landing page.

This is not a conference website.

This project is a digital editorial experience inspired by premium magazines and documentary storytelling.

The objective is to invite visitors into the world of Terra Madre Salone del Gusto before asking them to join the journey.

Emotion comes before information.

Story comes before booking.

People come before products.

---

# Editorial Philosophy

Every page should answer three questions.

1. What should the visitor feel?

2. What should the visitor understand?

3. What should the visitor want to do next?

Every section must contribute to one of these goals.

If it doesn't, it does not belong on the website.

# Design Philosophy

The website should resemble a printed editorial publication rather than a traditional Bootstrap website.

Design priorities:

• Photography first
• Typography second
• Interface third

Interface should never compete with photography.

Whitespace is an active design element.

Silence is part of the experience.

---

# Photography Principles

Photography is the primary storytelling medium.

Images are not decorative.

Images are not illustrations.

Images are the narrative.

Prefer:

• authentic moments
• real people
• craftsmanship
• emotion
• landscape with purpose
• documentary style

Avoid:

• stock photography
• generic smiling groups
• staged corporate scenes
• visual clutter
• unnecessary overlays

---

# Editorial Principles

Editorial statements are not captions.

Editorial statements express ideas.

Maximum length:

18 words.

They should inspire reflection rather than describe the image.

---

# Typography

Display

Publico Headline Medium

Used for:

• Hero titles
• Scene titles
• Editorial statements
• Interludes

---

Body

Google Sans

Used for:

• paragraphs
• navigation
• interface
• supporting information

---

Quotes

Open Sans Italic

Used only for quotations and personal reflections.

---

# Color Philosophy

The interface remains neutral.

Photography provides most of the visual color.

Avoid decorative color usage.

Use restrained accents only when necessary.

---

# Layout Principles

Prefer:

large photography

generous whitespace

simple grids

editorial rhythm

strong hierarchy

Avoid:

Bootstrap cards

boxed layouts

sliders

carousels

heavy gradients

complex overlapping elements

visual noise

---

# Editorial Rhythm

Every chapter should breathe.

Preferred rhythm:

Photo

↓

Editorial Statement

↓

Whitespace

↓

Supporting Information

↓

Pause

↓

Next Scene

Scrolling should feel calm and intentional.

---

# Motion Principles

Motion supports storytelling.

Motion never becomes decoration.

Use:

subtle fade

slow reveal

gentle parallax

small image movement

Avoid:

fast transitions

large animations

constant motion

scroll hijacking

---

# Accessibility

Typography must remain readable.

Contrast must remain high.

Images should include meaningful alt text.

Navigation must remain intuitive.

Animations should respect reduced-motion preferences.

---

# Development Principles

Bootstrap is an implementation framework.

It is not the design language.

Avoid obvious Bootstrap components whenever possible.

Custom layouts should support the editorial identity.

---

# Codex Workflow

Before every implementation sprint:

Read:

docs/creative-bible-v1.md

Read any relevant editorial document.

If documentation conflicts with implementation,
the documentation wins.

If required documentation is missing,
stop and report the missing file.

Never invent new visual patterns without explicit approval.

---

# Quality Checklist

Before considering any scene complete:

Does photography lead the experience?

Does typography feel editorial?

Is there enough whitespace?

Is the interface invisible?

Does the visitor naturally continue scrolling?

Does the scene support the overall narrative?

If any answer is "No",

the scene is not finished.

---

# North Star

If a visitor remembers only one feeling after leaving this website, it should be:

> Food is a story told by people.

Everything on this website should reinforce that idea.

## Vertical Rhythm

Editorial scenes should not imitate hero sections.

The visitor should be able to experience both the photography and the editorial statement within the same viewport whenever possible.

Desktop editorial scenes should generally remain between 650px and 850px in height.

Full-screen layouts should be reserved only for the Hero or exceptional storytelling moments.
