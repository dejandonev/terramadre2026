# Overview

Version 1.0 introduces the first complete editorial experience for the Terra Madre Salone del Gusto 2026 website.

Instead of a traditional event landing page, the project presents Terra Madre through a sequence of editorial chapters inspired by premium magazines and documentary storytelling.

The experience gradually moves the visitor from inspiration to practical travel information while maintaining a consistent visual language throughout the website.
